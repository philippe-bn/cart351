1. ***Face De Book* by Kerven-Laurent Casimir** <br>
A fake social media page on which the user can type in fields and have the information returned to the screen in a phishing scam manner. It issues a critique of social media's data collection (specifically pointing to Facebook), and the risks related to giving your private information to these databases and what can happen if one is not careful. <br>
I loved the design of the page, it looked very clean and professional which helped sell the concept. I found that the handling of the data could have been a bit more interesting, to further push the concept of a phishing scam and better relate to the readings. <br>
It would be nice to compile users' information into a JSON file and make it so users can "pay" on a button and see all the other users' "private" information. I also agree with Jack's idea of adding an incentive to log in. <br>
